# Локальный редактор портфолио

1. Нужны установленный **Node.js 22 или новее** и Google Chrome. Дополнительные пакеты не нужны.
2. Дважды нажмите `start-editor.bat`. Chrome откроется после запуска сервера.
3. Оставьте окно сервера открытым. Для остановки нажмите в нём Ctrl+C.

Слева выберите проект или нажмите «Новый проект». Введите название, год,
автора Solo / fantastic little splash, типы проекта и роли. «Дублировать проект»
создаёт отдельный несохранённый проект с новыми идентификаторами.

Внизу формы выберите тип блока и нажмите «Добавить блок». На каждой карточке
есть перемещение вверх/вниз, копирование, Visible/Hidden, сворачивание и удаление с подтверждением.
Перетаскивайте карточки за ручку ⋮⋮. Collapse all / Expand all управляют только
интерфейсом и не меняют JSON. Фильтр блоков также не меняет порядок; drag-and-drop
доступен только в режиме All blocks. Для галерей и списков можно добавлять,
удалять и перемещать отдельные записи. Язык текста можно оставить неуказанным
либо выбрать English или Ukrainian; перевод не требуется.

Предпросмотр справа обновляется при вводе и использует рендерер и CSS сайта.
Кнопки «Компьютер» и «Телефон» переключают ширину области. В предпросмотре
ссылки отключены, чтобы не покидать страницу. Видео требует интернета.

Изображения сначала подготовьте в Portfolio Image Converter, затем скопируйте
в папку `assets` или её подпапки. Нажмите «Обновить список изображений» и
выберите preview / large / zoom. Старые src также доступны. Редактор не
конвертирует, не загружает и не удаляет изображения.

**Save · Сохранить** записывает выбранный проект в `data/projects.json`.
До нажатия этой кнопки публичные данные не меняются. После сохранения изменения
видны на локальном сайте; отправки в интернет нет. Обновите открытую страницу
сайта, чтобы увидеть сохранённую версию.

Несохранённые изменения отмечены в верхней строке. Браузер хранит рабочий
черновик и предлагает восстановить его после повторного открытия. Это
дополнительная страховка, а не замена Save. При переключении проекта черновик
заменяется после подтверждения. При закрытии страницы появляется предупреждение.

Перед каждой записью сервер создаёт точную копию прежнего JSON в
`.editor-backups`, затем записывает новый файл через временный файл и rename.
Ошибка до rename оставляет исходный JSON на месте. Если файл изменился
другой программой или другой вкладкой, Save остановится: скопируйте нужные
тексты и обновите редактор перед повторным сохранением.

«Резервные копии» позволяет восстановить **весь список проектов** на выбранный
момент. Перед восстановлением также создаётся копия текущих данных.
Копии и локальные временные файлы исключены из Git. Не удаляйте резервные копии,
пока не убедитесь, что нужные изменения сохранены.

Сервер доступен только на `127.0.0.1`. Обычно адрес редактора —
`http://127.0.0.1:8765/editor/index.html`; если порт занят, сервер выбирает
следующий свободный порт и открывает правильный адрес в Chrome. Адрес также
напечатан в окне сервера. Для публичного сайта замените `/editor/index.html`
на `/index.html` в этом адресе. Сервер не запускается на внешнем интерфейсе.
Черновики браузера привязаны к адресу с портом; при другом порте они не видны.

Проверка реализации: `node --test editor/editor.test.cjs`. Проверка создаёт
временную копию сайта в системной папке temp, запускает Chrome, создаёт проект,
сохраняет его, перезапускает сервер и проверяет восстановление. Рабочие данные
портфолио не изменяются. Для нестандартного пути Chrome задайте `CHROME_PATH`.

Внутри редактора загрузка/сохранение отделены от форм через API сервера.
В будущем их можно заменить сетевым хранилищем; сам рендерер остаётся общим.

## Интерфейс редактора

- Потяните вертикальный разделитель между формой и Live Preview, чтобы изменить ширину панелей. Двойной щелчок возвращает пропорцию 50/50; выбранная ширина сохраняется в браузере.
- Кнопка «На весь экран» оставляет только Live Preview. Для возврата нажмите кнопку ещё раз или Escape.
- Project Types и Roles выбираются из общего списка. Начните ввод для поиска, нажмите Enter для добавления нового значения, нажмите на выбранную метку для удаления. Новые варианты сохраняются локально для следующих проектов.
- Gallery поддерживает 1–3 колонки, глобальные или индивидуальные горизонтальный/вертикальный gaps и связанный режим. Изображения внутри Gallery можно сворачивать отдельно или все сразу. На мобильном экране элементы автоматически располагаются в одну колонку без обрезки, а Vertical gap разделяет целые элементы вместе с подписями.
- Название видео служит доступным именем плеера. Чтобы показать его визуально над видео, включите «Показывать название видео на странице»; подпись под видео задаётся отдельно.
- Caption виден под изображением, Alt text предназначен для доступности, Archive description показывается в просмотре Archive, а Photo credit — в lightbox проекта и Archive только при заполненном значении.
- Над текстовым блоком находится компактная панель Bold, Italic, Underline, Strikethrough, Link, цветов и Clear formatting. Старое поле `text` сохраняется как plain-text fallback; безопасное локальное форматирование хранится отдельно в `richText`.
- Раздел **Project Styles** меняет глобальную типографику и интервалы всех страниц проектов. Изменения сразу видны в Preview, а Save записывает их отдельно в `data/project-styles.json` с резервными копиями в `.editor-backups/styles`. Reset возвращает одно поле, Reset all styles — все исходные значения после подтверждения.
- Новые Spacer используют множитель глобальной базовой единицы и показывают рассчитанную высоту. Старые `small / medium / large` сохраняют прежние 16 / 40 / 80 px, пока вы явно не нажмёте преобразование.
- **Show in 3D objects** не зависит от Show in Archive. Если хотя бы одно изображение отмечено, главная страница берёт для 3D-текстур отмеченные `preview` (с fallback на старые поля источника). Если отметок нет или данные проектов не загрузились, используется прежний список `imagePool` из `script.js`; он намеренно не сопоставляется с проектами автоматически.
- **Text-based blocks width & Image Layout** в Project Styles задаёт глобальную ширину Text, Links/Materials и Exhibitions: Custom, Full content width или совместимые `70ch`. Каждый такой блок может наследовать глобальное значение либо выбрать собственный Custom/Full режим. Диапазон индивидуальной ширины — 240–1600 px; мобильная ширина всегда ограничена контейнером.
- **Choose image** открывает изменяемую визуальную библиотеку с поиском, Used/Unused/Draft/Hidden-статусами, фильтрами по проекту и ориентации, сортировкой, миниатюрами, разрешением и группой Preview/Large/Zoom. Maximize/Restore, размер окна и вертикальный разделитель запоминаются в браузере. «Найден» означает отдельный физический файл, `fallback` — повторное использование доступного источника. Новые импорты получают точную локальную дату; дата старого файла помечается как приблизительная. Старые ручные селекторы находятся в Advanced. В Gallery кнопка «Из библиотеки» поддерживает множественный выбор.
- **Import images** копирует выбранные изображения, а **Import folder** — поддерживаемые изображения и `conversion-manifest.json` из папки в `assets/imported`, сохраняя относительные подпапки и не удаляя оригиналы. Посторонние файлы из выбранной папки пропускаются. Поддерживаются JPEG, PNG, WebP и AVIF, до 50 MB на изображение; manifest ограничен 2 MB и проверяется как JSON. Совпадающие имена получают безопасный числовой суффикс и не перезаписываются.
- Редактор обнаруживает все файлы с точным именем `conversion-manifest.json` внутри `assets`, поэтому manifest нескольких импортированных наборов сохраняются и снова обнаруживаются после перезапуска. Кнопка **Import images** намеренно не предлагает JSON; чтобы включить manifest, используйте **Import folder**. Без документированного примера формата редактор не интерпретирует его содержимое и не угадывает структуру. Надёжная автоматическая группировка работает для файлов в одной папке с явными суффиксами `-preview`, `_preview`, `.preview`, а также `large` и `zoom`; остальные файлы остаются самостоятельными fallback-источниками.
