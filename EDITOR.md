# Локальный редактор портфолио

1. Нужны установленный **Node.js 22 или новее** и Google Chrome. Дополнительные пакеты не нужны.
2. Дважды нажмите `start-editor.bat`. Chrome откроется после запуска сервера.
3. Оставьте окно сервера открытым. Для остановки нажмите в нём Ctrl+C.

Слева выберите проект или нажмите «Новый проект». Введите название, год,
автора Solo / fantastic little splash, типы проекта и роли. «Дублировать проект»
создаёт отдельный несохранённый проект с новыми идентификаторами.

Внизу формы выберите тип блока и нажмите «Добавить блок». На каждой карточке
есть перемещение вверх/вниз, копирование и удаление с подтверждением.
Перетаскивайте карточки за ручку ⋮⋮. Для галерей и списков можно добавлять,
удалять и перемещать отдельные записи. Язык текста можно оставить неуказанным
либо выбрать English или Ukrainian; перевод не требуется.

Предпросмотр справа обновляется при вводе и использует рендерер и CSS сайта.
Кнопки «Компьютер» и «Телефон» переключают ширину области. В предпросмотре
ссылки отключены, чтобы не покидать страницу. Видео требует интернета.

Изображения сначала подготовьте в Portfolio Image Converter, затем скопируйте
в папку `assets` или её подпапки. Нажмите «Обновить список изображений» и
выберите preview / large / zoom. Старые src также доступны. Редактор не
конвертирует, не загружает и не удаляет изображения.

**Save · Сохранить** записывает выбранный проект в `data/projects.json`.
До нажатия этой кнопки публичные данные не меняются. После сохранения изменения
видны на локальном сайте; отправки в интернет нет. Обновите открытую страницу
сайта, чтобы увидеть сохранённую версию.

Несохранённые изменения отмечены в верхней строке. Браузер хранит рабочий
черновик и предлагает восстановить его после повторного открытия. Это
дополнительная страховка, а не замена Save. При переключении проекта черновик
заменяется после подтверждения. При закрытии страницы появляется предупреждение.

Перед каждой записью сервер создаёт точную копию прежнего JSON в
`.editor-backups`, затем записывает новый файл через временный файл и rename.
Ошибка до rename оставляет исходный JSON на месте. Если файл изменился
другой программой или другой вкладкой, Save остановится: скопируйте нужные
тексты и обновите редактор перед повторным сохранением.

«Резервные копии» позволяет восстановить **весь список проектов** на выбранный
момент. Перед восстановлением также создаётся копия текущих данных.
Копии и локальные временные файлы исключены из Git. Не удаляйте резервные копии,
пока не убедитесь, что нужные изменения сохранены.

Сервер доступен только на `127.0.0.1`. Обычно адрес редактора —
`http://127.0.0.1:8765/editor/index.html`; если порт занят, сервер выбирает
следующий свободный порт и открывает правильный адрес в Chrome. Адрес также
напечатан в окне сервера. Для публичного сайта замените `/editor/index.html`
на `/index.html` в этом адресе. Сервер не запускается на внешнем интерфейсе.
Черновики браузера привязаны к адресу с портом; при другом порте они не видны.

Проверка реализации: `node --test editor/editor.test.cjs`. Проверка создаёт
временную копию сайта в системной папке temp, запускает Chrome, создаёт проект,
сохраняет его, перезапускает сервер и проверяет восстановление. Рабочие данные
портфолио не изменяются. Для нестандартного пути Chrome задайте `CHROME_PATH`.

Внутри редактора загрузка/сохранение отделены от форм через API сервера.
В будущем их можно заменить сетевым хранилищем; сам рендерер остаётся общим.
